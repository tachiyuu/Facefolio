Quiet by design.
Precise by construction.

Facefolio exists to remove noise from Facebook, so its own interface has to be the calmest thing on screen: tonal surfaces instead of shadows, one accent colour from Material You, and motion that only ever explains what just happened.

Launch sequence

The first frame is the system splash: plain surface, no icon, the same colour Compose draws next. Nothing jumps, nothing is redrawn: the tile eases in from 96 to 112 dp, the name arrives, and the feed opens out of the mark once Facebook has actually painted — not when a timer says so.

  1. 0 ms
    System handoffPlain surface colour, held until Compose has drawn its first frame. The OS splash shows no icon, so there is no launcher icon to jump from and the switch is invisible.
  2. 120 ms
    SettleCircle morphs to a 36 dp squircle, icon scales 0.62 → 0.60, wordmark rises 8 dp. 520 ms, emphasized.
  3. 640 ms →
    Alive, not busyA slow specular sweep along the strokes. A hairline progress only appears if loading passes 1.2 s, so fast launches never flash a bar.
  4. ready
    RevealOn WebView’s first visual-state callback the mark recedes and the feed opens in a circle from its centre. 620 ms, emphasized decelerate.

Engineering notes

How the launch stays honest on a cold start, a slow network and a low-end phone.

First-frame parity

core-splashscreen draws the same vector on the same surface colour. Compose’s first frame starts in that exact state, so the handoff has no seam — the old splash re-drew the mark from scratch.

Ready means painted

The reveal waits for WebViewCompat.postVisualStateCallback after the injected scripts ran, never for a timer. An 8 s ceiling only exists so a stuck page still opens.

No flash for fast launches

The progress hairline is gated at 1.2 s. Warm starts reveal before it would ever show, so they feel instant instead of “loading”.

One render layer

Scale, alpha and clip run in graphicsLayer; nothing triggers layout during the sequence. The old ripples and coloured shadows cost overdraw on every frame.

Respect the system

With animations off, every step collapses to a 200 ms cross-fade. Colours come from dynamicColorScheme, with a baseline palette below Android 12.

Fail open

If Facebook changes and a hook stops matching, features degrade one by one and Settings says which. The app never shows a blank page because a selector broke.
